Engenharia AWS Serverless

Plataforma de Gestão de Horas de Terceiros de Tecnologia

Modernização completa de arquitetura on-premises fragilizada para ambiente AWS Serverless de alta performance e governança.

Cenário Legado (On-Premises) Jenkins / Bare-Metal
  • Infraestrutura: Máquina física dedicada vulnerável a falhas e instabilidade.
  • Complexidade: 16 fluxos fragmentados orquestrados no Jenkins.
  • Ingestão: Dependência de planilhas manuais e scripts de "raspa tela" instáveis.
  • Tempo de Execução: entre 5h30m e 6h00m.
  • Gap de Negócio: Ausência total de histórico de retrofits (ajustes retroativos).
Nova Arquitetura AWS AWS Serverless
  • Stack AWS: AWS EventBridge, AWS Step Functions e AWS Glue Jobs.
  • Simplificação: Redução de 16 para apenas 7 fluxos otimizados.
  • Governança: Eliminação de raspa-tela; utilização de bases democratizadas.
  • Performance: Redução do tempo para máximo de 30 minutos (>90% de ganho).
  • Novo Recurso de Negócio: Histórico completo e auditável de retrofits.
Tempo de Processamento ~6h ➔ 30min
Consolidação de Fluxos 16 ➔ 7
Fonte de Dados 100% Governança
Histórico Retrofits Disponível
